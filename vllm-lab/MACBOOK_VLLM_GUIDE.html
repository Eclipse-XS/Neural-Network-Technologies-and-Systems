Лабораторна робота №2

Запуск vLLM на MacBook Pro M3 Max

Інструкція для MacBook Pro M3 Max. Потрібно запустити мовну модель локально, підключити до неї Python-програму cli.py та продемонструвати роботу через Terminal.

Для цього використовуватимуться два вікна Terminal: в одному працюватиме сервер vLLM, в іншому — Python CLI.

Крок 1

Встановлення vLLM-Metal

Для запуску vLLM на MacBook з Apple Silicon використовується vLLM-Metal.

У Terminal послідовно виконай:

Terminal brew tap 
brew tap vllm-project/vllm-metal https://github.com/vllm-project/vllm-metal
Terminal brew install 
brew install vllm-project/vllm-metal/vllm-metal

Після завершення встановлення перевір, чи доступна команда:

Terminal перевірка версії 
vllm --version

Якщо версія відображається, можна переходити до запуску моделі.

Команди підготовлені для macOS, але на конкретному MacBook ще не перевірялися.
Крок 2

Завантаження та запуск мовної моделі

Для лабораторної обрано модель Qwen/Qwen2.5-1.5B-Instruct-AWQ, яка має менше ніж 3 мільярди параметрів.

Введи:

Terminal 1 (Сервер vLLM) vllm serve 
vllm serve Qwen/Qwen2.5-1.5B-Instruct-AWQ \
  --port 8000 \
  --max-model-len 2048 \
  --gpu-memory-utilization 0.50

Під час першого запуску vLLM завантажить модель із Hugging Face, після чого запустить локальний API-сервер на порту 8000.

Завантаження може зайняти кілька хвилин. Дочекайся повідомлення про готовність сервера.

Це вікно Terminal залиш відкритим. Сервер повинен працювати протягом усієї демонстрації.
Якщо vLLM повідомляє про несумісність моделі, спочатку потрібно підібрати підтримуваний checkpoint. Цю конфігурацію ще не перевірено на M3 Max.
Крок 3

Перевірка роботи сервера

Відкрий друге вікно Terminal і виконай:

Terminal 2 (Клієнт) curl GET /v1/models 
curl http://127.0.0.1:8000/v1/models

У відповіді має з'явитися JSON з інформацією про завантажену модель. Знайди поле id, наприклад:

Очікуваний фрагмент відповіді JSON JSON 
"id": "Qwen/Qwen2.5-1.5B-Instruct-AWQ"

Цей ідентифікатор потрібно використовувати під час запуску cli.py.

Якщо виникає Connection refused, перевір, чи завершилося завантаження моделі в першому Terminal.
Крок 4

Підготовка Python CLI

Для лабораторної тобі передадуть два файли:

  • cli.py — програма для надсилання запитань моделі через API.
  • requirements.txt — залежності Python.

Розмісти їх у папці lab2_vllm на робочому столі.

У другому Terminal перейди до цієї папки:

Terminal 2 перехід до каталогу 
cd ~/Desktop/lab2_vllm

Створи та активуй віртуальне середовище:

Terminal 2 створення та активація venv 
python3 -m venv .venv
source .venv/bin/activate

Встанови залежності:

Terminal 2 pip install 
python -m pip install -r requirements.txt

Це початкове налаштування. Під час наступних запусків достатньо перейти до папки й активувати .venv.

Крок 5

Запуск CLI та перевірка діалогу

У другому Terminal запусти:

Terminal 2 запуск cli.py 
python cli.py --model Qwen/Qwen2.5-1.5B-Instruct-AWQ

Після підключення до сервера з'явиться запрошення You:.

Введи перше запитання:

Введення запитання (You):
What is machine learning? Explain in two sentences.

Дочекайся відповіді та постав друге:

Введення запитання (You):
Give me one real-world example of it.

Друге запитання пов'язане з першим. Так можна перевірити, чи програма передає моделі історію розмови.

Для завершення введи:

Terminal 2 вихід з діалогу 
exit

Після виходу діалог автоматично збережеться у папці outputs/dialogs у форматі Markdown.

Крок 6

Експерименти з параметрами генерації

Для лабораторної потрібно продемонструвати, як змінюється поведінка моделі залежно від параметрів.

6.1. System prompt

System prompt задає інструкцію щодо стилю або правил відповіді.

Запусти:

Terminal 2 --system-prompt 
python cli.py \
  --model Qwen/Qwen2.5-1.5B-Instruct-AWQ \
  --system-prompt "You are a machine learning teacher. Explain concepts in simple English."

Постав запитання:

Введення запитання (You):
What is overfitting?

Перевір, чи модель дотримується заданого стилю. Заверши діалог через exit.

6.2. Temperature

Temperature регулює випадковість генерації: нижчі значення зазвичай дають більш передбачувані відповіді, вищі — різноманітніші.

Спочатку запусти:

Terminal 2 temperature = 0.2 
python cli.py --model Qwen/Qwen2.5-1.5B-Instruct-AWQ --temperature 0.2

Постав запитання:

Введення запитання (You):
Suggest three names for an AI assistant for students.

Заверши діалог і повторно запусти програму:

Terminal 2 temperature = 1.2 
python cli.py --model Qwen/Qwen2.5-1.5B-Instruct-AWQ --temperature 1.2

Постав те саме запитання.

Порівняй результати. Вища temperature може дати незвичнішу відповідь, хоча це не гарантується для кожного запиту.

6.3. Max tokens

max_tokens обмежує максимальну кількість токенів у згенерованій відповіді.

Спочатку:

Terminal 2 max-tokens = 30 
python cli.py --model Qwen/Qwen2.5-1.5B-Instruct-AWQ --max-tokens 30

Питання:

Введення запитання (You):
Explain five advantages of machine learning.

Потім:

Terminal 2 max-tokens = 200 
python cli.py --model Qwen/Qwen2.5-1.5B-Instruct-AWQ --max-tokens 200

Повтори те саме питання.

Порівняй довжину відповідей. За меншого ліміту модель може не встигнути завершити пояснення.

Крок 7

Демонстрація викладачу

Під час захисту потрібно показати:

  1. Запущений сервер vLLM у першому Terminal.
  2. Перевірку моделі командою curl http://127.0.0.1:8000/v1/models.
  3. Запуск cli.py у другому Terminal.
  4. Два послідовні запитання, щоб показати роботу моделі та збереження контексту.
  5. Повторний запуск із --system-prompt, --temperature або --max-tokens.
  6. Файли збережених діалогів у outputs/dialogs.
Фінал

Завершення роботи

Після демонстрації введи exit у Python CLI.

Потім повернися до першого Terminal і натисни Ctrl + C, щоб зупинити сервер vLLM.

Підсумок виконання

Результат: локально запущена мовна модель, працюючий Python CLI, експерименти з параметрами генерації та збережені діалоги.
