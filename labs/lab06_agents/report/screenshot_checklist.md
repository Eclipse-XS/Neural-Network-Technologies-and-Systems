# Скріншоти для оформлення

Скріншоти GUI не виготовлялися штучно. У notebook є справжні результати, завантажені зі збережених запусків. Для фінального оформлення методичка вимагає скріншоти роботи.

- [ ] LM Studio: локальний сервер та завантажена mistralai/ministral-3-3b.
- [ ] Notebook: фактичний /v1/models і метадані версій.
- [ ] Визначення чотирьох function_tool та їхні схеми.
- [ ] Фактологічний запит і реальні виклики функцій.
- [ ] Повна таблиця багатокрокової траєкторії.
- [ ] SQLiteSession: два пов'язані запити та збережені items.
- [ ] Ізольована сесія B і її відповідь без переданого псевдоніма.
- [ ] Той самий запит без інструментів і з ними.
- [ ] Підсумкова таблиця оцінок, включно з недоліками.

Чекліст не є підтвердженням наявності скріншотів. Статус цього пункту в аудиті — MANUAL.
