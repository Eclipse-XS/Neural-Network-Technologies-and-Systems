# Runtime outputs

Ця директорія призначена для нових локальних inference-результатів, metadata та
згенерованих фігур. Її вміст, крім цього пояснення, не версіонується. Перевірений
історичний запуск збережено компактно в `../evidence/`; notebook читає саме його,
тому аналітичні комірки виконуються без GPU. Runtime cache не є доказом сам по собі.
